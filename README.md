# PHITS in Visula Studio Code

Visual Studio Code Extension for creating PHITS input files

## Features

### Syntax highlighting

- Section title
- Parameters
- Comments
- Constants
- Formulas
- Keywords used in specific sections, etc.
- m, mat
- set
- infl
- tr
